Описание:
E-commerce - будем реализовывать систему платежей, однако подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина.
Установка:
1. Клонируйте репозиторий:
git@github.com:pannikolaserg-prog/E-commerce.git
Использование:
1. Откройте приложение в вашем PyCharm.
2. В модуле classes.py реализованы классы Product и Category, а также классы-наследники Smartphone и LawnGrass.
3. В том же модуле предусмотрена возможность сложения и добавления продуктов.
При сложении двух разноименных классов выбрасывается ошибка TypeError
4. В модуле utils.py описана функция для считывания файла .json.
5. В модуле main.py реализуется весь функционал пакетов проекта.
